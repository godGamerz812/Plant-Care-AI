# PlantCare Adventure AI

An open-source outdoor companion for the Hacktoberfest 2026 "Touch Grass" challenge.

## Challenge criteria covered

- Ask for location/preferences
- Suggest outdoor activities
- Generate a walking/hiking-style outdoor mission
- Suggest things to look for while outside
- Create an offline adventure checklist
- Let the user record observations/photos/notes
- Generate a small Adventure Journal after the walk

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
