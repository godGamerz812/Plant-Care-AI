# GitHub Skills: Intro to Repository Management — Submission Notes

**Project URL:** https://github.com/godGamerz812/Plant-Care-AI

PlantCare Adventure AI is a small Streamlit project for the Hacktoberfest Touch Grass theme. It offers outdoor nature/plant observation missions, things to look for, a reminder to put the phone away, and a simple local journal workflow.

**Important:** This app includes a Gemma-compatible endpoint adapter but does not claim a live Gemma endpoint is configured. The app uses safe built-in missions when no endpoint is configured.

This repository is also a project repo, but the screenshoted GitHub Skills challenge requires completing its own interactive GitHub exercise repository and attaching a screenshot of that exercise. A link to this application repository alone does not prove the GitHub Skills exercise has been completed.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
